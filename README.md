Автоматизация теста к API
Автоматизирован следующий сценарий:
    Клиент создает заказ.
    Проверяется, что по треку заказа можно получить данные о заказе.
Шаги автотеста:
    Выполнить запрос на создание заказа.
    Сохранить номер трека заказа.
    Выполнить запрос на получение заказа по треку заказа.
    Проверить, что код ответа равен 200.
Файлы проекта:
    configuration.py - содержит базовый адрес проекта и ручки API
    data.py - содержит набор тестовых данных
    sender_stand_request.py - файл запросов к серверу
    test_order_by_track.py - файл автотеста
    README.md - описание проекта
    requirements.txt - список библиотек
    screenshot.png - скриншот выполнения автотеста
